> - **Under Cursor:** SC-2, SC-3, SC-4, SC-5 are walked behaviorally. - **How the gate verdict aggregates.** All five sections use the same "treat `not-applicable` as `pass` per Section 4.5 aggregation" formulation; Section 4.5 aggregation rule defines that formulation precisely.

No residue of the old "all seven SCs behaviorally on both harnesses" framing survives. The reframe is internally consistent.
